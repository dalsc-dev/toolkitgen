# ToolkitGen Workspace Standing Rules

- Free tier only: Cloudflare Workers/Pages free limit (<25 MiB file, <20,000 files).
- Astro only; no React migration.
- Tool inputs processed locally; use copy.ts wording; no absolute privacy/security claims.
- Zero emoji glyphs in all code, content, and responses.
- Zero left-only border accents (`border-l-*`).
- Auto ads plus plain "Advertisement" label rules stay; no styled framing around ads.
- Performance budgets (TBT < 200ms) and hang budgets (<= 1000ms loop gap under 6x CPU throttle) strictly enforced.
- Zero fake data, zero invented search volumes, zero unverified claims.
- Label every time-sensitive fact "[Confirmed]" or "[Reported]" with source and date.
- Gaming content: Use game names only descriptively with "not affiliated with Rockstar Games, Take-Two, Sony or Microsoft". No PC claims for GTA 6 (console only).
- No scraping Google.
- No push to remote main until all CI gates pass.
- Stop for user confirmation after each phase.
- Use Planning mode: Produce an Implementation Plan artifact and Task List artifact per phase and wait for user approval before executing.
