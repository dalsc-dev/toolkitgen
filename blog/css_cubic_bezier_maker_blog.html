Understanding Easing Functions

Easing functions control how an animation progresses over time. Without easing, animations move at a constant speed, feeling mechanical and unnatural. Easing mimics how objects move in the real world—they accelerate, decelerate, and sometimes overshoot.

Why Easing Matters

  • Natural feel: Real objects don't move linearly
  • User experience: Proper easing guides attention and expectations
  • Polished appearance: Subtle easing elevates design quality
  • Personality expression: Different easing styles convey different moods

The Four Standard Easing Keywords

CSS provides four built-in easing keywords:

ease

ease is the default value, equivalent to cubic-bezier(0.25, 0.1, 0.25, 1.0). It starts slowly, accelerates, then decelerates—a versatile all-purpose easing.

linear

linear maintains constant speed throughout the animation: cubic-bezier(0, 0, 1, 1). Best for opacity fades or color shifts where unnatural acceleration feels wrong.

ease-in

ease-in starts slowly and accelerates: cubic-bezier(0.42, 0, 1, 1). Perfect for elements entering the viewport or exits that accelerate away.

ease-out

ease-out starts quickly and decelerates: cubic-bezier(0, 0, 0.58, 1). Ideal for elements appearing on screen with a confident pop.

Introducing Cubic-Bezier

cubic-bezier() is a mathematical function that defines a cubic Bézier curve. It accepts four parameters representing control points:

cubic-bezier(x1, y1, x2, y2)

Understanding the Control Points

Imagine a square where the animation moves from corner to corner. The curve connecting them is shaped by two control points:

  • P0: Start point (0, 0) - fixed
  • P1: First control point (x1, y1) - defines curve shape near start
  • P2: Second control point (x2, y2) - defines curve shape near end
  • P3: End point (1, 1) - fixed

The X-Axis vs Y-Axis

X-axis: Animation progress (time), must be between 0 and 1. Y-axis: Output value (animation progress), can exceed 0-1 for overshoot effects!

Understanding Animation Timing

Acceleration (ease-in effects)

Curves that start steep and flatten out create acceleration. The Y values increase slowly at first, then rapidly.

Deceleration (ease-out effects)

Curves that start flat and steepen create deceleration. The Y values increase rapidly at first, then slow down.

Overshoot Effects

Curves that exceed Y=1 create overshoot—the animation goes past its target and returns. This creates elastic, spring-like effects.

Anticipation Effects

Curves that dip below Y=0 create anticipation—the animation starts backward before moving forward, creating natural "wind-up" effects.

Applying CSS Cubic-Bezier

Using with transitions

.element {
    transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

Using with animations

.element {
    animation: slideIn 0.5s cubic-bezier(0.68, -0.55, 0.27, 1.55);
}

@keyframes slideIn {
    from { transform: translateX(-100%); }
    to { transform: translateX(0); }
}

Using with animation-timing-function

.element {
    animation-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1);
}

Browser Compatibility

cubic-bezier() has excellent browser support, working in all modern browsers including Chrome, Firefox, Safari, Edge, and Opera.

Vendor Prefixes

For older browsers, you may need the -webkit- prefix:

.element {
    -webkit-transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1);
    transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

Creating Bounce Effects

True bounce effects require the Y-value to exceed 1, creating overshoot. The curve's Y values can go beyond the 0-1 range:

Gentle Bounce (10%)

cubic-bezier(0.68, -0.2, 0.32, 1.2)

Moderate Bounce (25%)

cubic-bezier(0.68, -0.55, 0.27, 1.55)

Strong Bounce (50%)

cubic-bezier(0.175, 0.885, 0.32, 1.275)

Creating Spring Effects

Spring animations involve multiple oscillations. While CSS can't do true multi-oscillation springs, you can simulate spring-feel with overshoot:

Underdamped (spring-like)

cubic-bezier(0.5, 1.5, 0.75, 1.25) - Overshoots and settles

Overdamped (controlled)

cubic-bezier(0.2, 0.8, 0.2, 1) - Smooth without overshoot

Choosing the Right Easing

UI Transitions

For most UI interactions (modals, tooltips, menus), use smooth easing that doesn't overshoot:

  • Entrance: cubic-bezier(0, 0, 0.2, 1) - quick in
  • Exit: cubic-bezier(0.4, 0, 1, 1) - quick out
  • Standard: cubic-bezier(0.4, 0, 0.2, 1) - balanced

Loading Animations

Loops and spinners work well with linear or slight easing to maintain consistent rhythm.

Emphasis Animations

For elements that need to grab attention, use bounce or overshoot easing.

Page Transitions

Page-level animations benefit from smooth, confident easing that conveys stability and professionalism.

Performance Considerations

GPU-Accelerated Properties

For smooth animations, stick to properties that trigger GPU acceleration:

  • transform: translate, scale, rotate
  • opacity: fade effects
  • filter: blur, brightness (use sparingly)

Avoid Layout Thrashing

Animating width, height, margin, padding, top, left triggers layout recalculations. These are "expensive" and cause jank.

Using will-change

Hint the browser to optimize ahead of time:

.element {
    will-change: transform;
}

Always test easing in context. What looks perfect in the generator might feel wrong in your actual interface. Consider:

  • Screen size: Easing perception varies with element size
  • Duration: Timing and easing interact; adjust together
  • Context: Match easing to your overall design language
  • Accessibility: Consider prefers-reduced-motion for users who need it

Frequently Asked Questions About CSS Cubic-Bezier

1. What is cubic-bezier in CSS?

cubic-bezier is a CSS easing function that defines a custom acceleration curve for animations and transitions using mathematical control points.

3. What does cubic-bezier(0.25, 0.1, 0.25, 1) mean?

This is the "ease" preset. The four values are the (x,y) coordinates of the two control points that shape the curve.

4. Can cubic-bezier values exceed 0-1?

Yes! Y values (y1, y2) can be less than 0 (anticipation) or greater than 1 (overshoot/bounce). Only x values must stay between 0-1.

5. What is the difference between ease and cubic-bezier?

"ease" is a keyword shorthand for a specific cubic-bezier: cubic-bezier(0.25, 0.1, 0.25, 1)

6. How do I create a bounce effect with cubic-bezier?

Set y2 above 1 (like cubic-bezier(0.68, -0.55, 0.27, 1.55)) to create overshoot that settles back, simulating bounce.

7. What is the best cubic-bezier for a smooth transition?

cubic-bezier(0.4, 0, 0.2, 1) is excellent for smooth, modern transitions. It's the Material Design standard.

10. What cubic-bezier creates an elastic effect?

cubic-bezier(0.68, -0.55, 0.27, 1.55) creates a gentle elastic bounce effect.

13. What cubic-bezier values are most commonly used?

14. How does cubic-bezier relate to animation duration?

Easing and duration work together. Faster durations require gentler easing; longer durations can accommodate more dramatic curves.

15. Can cubic-bezier create shake effects?

For shake effects, use CSS keyframes rather than single easing functions. Easing controls the overall curve, not path direction.

16. What cubic-bezier creates a linear effect?

cubic-bezier(0, 0, 1, 1) is equivalent to the "linear" keyword.

17. How do I create an anticipation effect?

Set y1 below 0 (like cubic-bezier(0.42, -0.3, 0.58, 1)) to create a backward motion before the main animation.

18. Can cubic-bezier values be negative?

Y values (y1, y2) can be negative for anticipation effects. X values must remain between 0 and 1.

19. What is the difference between cubic-bezier and steps()?

cubic-bezier creates smooth curves; steps() creates discrete jumps. steps() is for choppy, digital effects.

20. How do I combine multiple easing effects?

For complex easing sequences, use multiple animations, JavaScript libraries, or carefully crafted keyframes.

21. Does cubic-bezier affect animation direction?

No, cubic-bezier only controls timing/progression, not direction. For reverse animations, use the reverse direction or invert keyframes.

22. What cubic-bezier mimics iOS animations?

23. How do I make animations feel natural?
