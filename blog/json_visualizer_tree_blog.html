Understanding JSON Structure

JSON (JavaScript Object Notation) is the universal data format. Understanding its structure is essential for effective visualization and manipulation.

JSON supports six data types:

  • Object - {key: value} pairs
  • Array - ordered values [a, b, c]
  • String - "text"
  • Number - integers and floats
  • Boolean - true or false
  • Null - null

Data Type Indicators

In our viewer, each type is visually indicated:

  • Objects: {} braces, blue highlight
  • Arrays: [] brackets, green highlight
  • Strings: "" quotes, green text
  • Numbers: no quotes, orange text
  • Booleans: purple text
  • Null: gray text

Common JSON Patterns

Understanding common patterns helps interpretation:

API Response

{
  "status": "success",
  "data": [...],
  "timestamp": "2024-01-01"
}

Paginated Data

{
  "items": [...],
  "page": 1,
  "totalPages": 10,
  "hasMore": false
}

User Profile

{
  "id": "123",
  "name": "John",
  "settings": {
    "theme": "dark",
    "notifications": true
  }
}

Nested Relationships

{
  "categories": [{
    "id": 1,
    "items": [...]
  }]
}

FAQ: JSON Visualization

1. Why is my JSON invalid?

Common causes: trailing commas, single quotes, comments. Use a validator to check.

2. How do I fix parsing errors?

Check for missing quotes, brackets, or commas. Our validator shows error location.

3. What's the difference between object and array?

Objects have key-value pairs {}. Arrays are ordered lists [].
