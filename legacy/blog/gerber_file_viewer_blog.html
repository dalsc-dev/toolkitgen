Understanding the Gerber Format

The Gerber format, officially known as RS-274X, is the industry-standard file format for describing printed circuit board artwork. Developed by RS Data, this format defines how geometric information—copper layers, solder mask, silkscreen, drill data, and more—is communicated to PCB manufacturers. Every PCB fabricator worldwide accepts Gerber files as the universal language of PCB manufacturing.

When you design a PCB in any modern software, the tool generates a set of Gerber files that represent each layer of your board. These files are essentially 2D vector drawings that the manufacturer's equipment uses to create the physical board. The format is elegant in its simplicity—it describes circles, lines, arcs, and polygons using coordinate-based commands that any board shop can interpret.

Our free Gerber viewer takes these technical files and renders them visually, making it easy to verify your design before sending it to fabrication. This eliminates the need for expensive software just to check your work before manufacturing.

Essential Gerber File Types

Every PCB design produces a standard set of Gerber files, and understanding what each layer represents ensures your board will be manufactured correctly. The copper layers (GTL for top, GBL for bottom, and additional files for inner layers in multi-layer boards) define where the actual conductive traces will exist on the finished board.

The solder mask layers (GTS for top, GBS for bottom) define where the green (or other color) protective coating will be applied. These are typically inverted—areas where you want solder mask will be excluded from the drawing. Silkscreen layers (GTO on top, GBO on bottom) define the white text and symbols that appear on the finished board.

Additional important files include the drill file (NC Drill or TXT) that tells the manufacturer where to drill holes, the outline file (GKO) that defines the board's physical shape, and paste files (GTP/GBP) for surface mount assembly. Common Gerber Inspection Issues

One of the most common problems is misalignment between layers. If your top and bottom layers don't align properly, components won't line up with pads and the board may be unusable. This typically happens when the design origin wasn't set correctly or when files were exported from different coordinate systems.

Another frequent issue is missing or incorrect solder mask aperture settings. If the solder mask is improperly defined, you might get unintended coverage on pads that should be exposed for soldering, or you might see slivers where the mask pulls away from narrow traces. These problems can cause assembly difficulties or even field failures.

Incomplete designs sometimes get exported—files might be missing layers that the designer thought were included. Our completeness checker automatically identifies which standard layers are present and which might be missing from your upload.

Understanding Gerber Coordinate Systems

Gerber files can use different coordinate formats and origins, which sometimes causes confusion when viewing files from different sources. Understanding whether your files use absolute or incremental coordinates, and where the origin point is located, helps you correctly interpret what you're seeing.

Most PCB software places the origin at the bottom-left corner of the design, but some place it at the top-left or even at the center. Gerber coordinates can be specified in inches or millimeters, and the number of decimal places affects precision. Modern Gerber files in RS-274X format include specification of these parameters within the file header.

Our coordinate system analyzer automatically detects these settings and helps you understand how your files are organized. This is particularly useful when working with designs from multiple sources or when converting between different software platforms.

Working with Drill Files

Drill files are typically formatted in Excelon (N/C) format or as plain text, and they work alongside your Gerber files to tell the manufacturer exactly where to drill each hole. These files define hole sizes, positions, and sometimes plating information for through-hole versus non-plated holes.

When inspecting your drill data, ensure that hole sizes match your expectations—metric versus imperial units can sometimes cause confusion if the manufacturer expects different units than what your design uses. Also check that any slot holes or complex shapes are properly defined. Our drill file inspector visualizes your drill data alongside the copper layers for easy verification.

Gerber vs Other Formats

While Gerber is the universal standard for PCB manufacturing, other formats exist. ODB++ (now called Valor) is a more comprehensive format that includes both design data and manufacturing information in a single package. IPC-2581 is an emerging standard designed to eventually replace Gerber with a more feature-rich alternative.

Most manufacturers still prefer Gerber because their equipment was designed to work with it and the format is universally supported. However, if your software supports it, exporting to ODB++ can sometimes provide additional verification options. Our format conversion helper explains the different options available.

For most hobbyists and professionals, understanding Gerber is sufficient—it's the format that will work everywhere and with every manufacturer. The skills you develop inspecting Gerber files transfer to understanding any manufacturing output format you might encounter.

The Future of Gerber and PCB Documentation

While Gerber has been the standard for decades, the PCB industry continues to evolve. Newer formats like IPC-2581 offer enhanced capabilities including built-in design rule verification and more efficient data representation. However, Gerber's simplicity and universal support ensure it will remain relevant for years to come.

Different layers typically have different colors by convention—copper might show as green or gold, solder mask as green or another color, silkscreen as white. 6. What's the difference between GTS and GTP?

GTS is Top Solder Mask (the coating), while GTP is Top Paste (for solder paste stencil creation). These serve completely different manufacturing purposes—confusing them causes significant fabrication problems. Our layer type identifier explains each file's purpose.

9. What should I do if layers don't align?

This usually indicates an export problem or coordinate system mismatch. Check your software's Gerber export settings, particularly the origin point. In some cases, you may need to adjust the offset in your original design software and regenerate the files.

11. What is the GKO file?

GKO (Gerber Keep Out) defines the board outline—where the edges of the PCB will be cut. Without this file, the manufacturer won't know what shape to cut your board. Our viewer automatically includes the outline when present.

15. What's the difference between RS-274 and RS-274X?

RS-274 is the older format requiring separate files for each aperture definition. RS-274X (extended Gerber) embeds aperture tables in the file itself, making files self-contained and less prone to errors. RS-274X is the modern standard—our viewer supports both but assumes RS-274X for most contemporary files.
