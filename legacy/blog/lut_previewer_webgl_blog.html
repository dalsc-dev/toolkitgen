Understanding LUTs

LUT (Look-Up Table) is a color transformation table. It maps input colors to output colors, enabling consistent color grading across different media.

LUTs are used for:

  • Film color grading
  • Log to Rec.709 conversion
  • Creative color looks
  • Consistent color across shots
  • Broadcast standard compliance

Types of LUTs

Different LUT types serve different purposes:

  • 1D LUTs - Brightness/contrast only
  • 3D LUTs - Full color transformation
  • Technical LUTs - Log conversions
  • Creative LUTs - Artistic color looks

How LUTs Work

LUTs transform colors mathematically:

Processing Pipeline

  1. Input image is read
  2. Each pixel color is mapped through LUT
  3. New color values are output
  4. Result shows graded image

3D LUT Structure

3D LUTs map RGB to RGB in a 3D cube:

  • Red values define position on one axis
  • Green values define position on second axis
  • Blue values define position on third axis
  • Intersection gives output color

Troubleshooting LUTs

Common issues and solutions:

Check input color space matches LUT design.

FAQ: LUT Previewer

1. What file formats are supported?

.cube format is most common and supported.

2. Can I create LUTs in this tool?

No, this tool is for preview. Use grading software to create.

3. Does it work with videos?

Works best with images. Video support varies by format.

4. How do I apply multiple LUTs?

Apply in sequence - technical then creative.

5. Why does LUT look different on different images?

LUTs change color relationship, not absolute color. Works differently on different sources.

6. Can I export graded images?

Yes, save graded output as new image file.

7. What is neutral LUT?

LUT that makes no color changes - used for testing.

8. How do I know if LUT is working?

Compare before/after. Colors should change predictably.

9. What's the difference between 1D and 3D LUTs?

1D handles grayscale only. 3D handles full color.

10. How many colors can LUT represent?

Typically 33x33x33 or 65x65x65 resolution.
