Understanding MAC Addresses

MAC (Media Access Control) address is a unique identifier assigned to network hardware. Every device with networking capability - including computers, phones, routers, and IoT devices - has a unique MAC address.

MAC addresses serve several purposes:

  • Device identification on local networks
  • Network access control
  • Device fingerprinting
  • Security tracking
  • Vendor identification

MAC Address Format

MAC addresses are 48-bit addresses written as 6 pairs of hexadecimal digits:

XX:XX:XX:XX:XX:XX
 |  |  |  |  |  |
 +--+--+--+--+--+-- Vendor ID (3 bytes)
 +-------------+-- Device ID (3 bytes)

Common Formats

Multiple representations are used:

  • XX:XX:XX:XX:XX:XX (colon-separated)
  • XX-XX-XX-XX-XX-XX (hyphen-separated)
  • XXXX.XXXX.XXXX (dot-separated)
  • XXXXXXXXXXXX (no separators)

MAC Address Structure

Understanding the two components:

OUI (Organizationally Unique Identifier)

First 3 bytes (24 bits) identify the manufacturer. Assigned by IEEE to ensure uniqueness.

NIC (Network Interface Controller) Specific

Last 3 bytes identify the specific device. Assigned by manufacturer.

Address Types

  • Universal Administered - Assigned by manufacturer
  • Local Administered - Manually assigned, not unique
  • Multicast - First byte ends in odd number
  • Broadcast - All Fs: FF:FF:FF:FF:FF:FF

Security Considerations

Security implications exist:

MAC Spoofing

Attackers can forge MAC addresses. Don't rely solely on MAC for security.

Randomized MACs

Modern iOS/Android use random MAC for scanning. Can't always track.

Privacy Concerns

MAC addresses are unique identifiers. Can track users across networks.

Best Practices

  • Use MAC filtering but not as sole security
  • Combine with other authentication
  • Update vendor database regularly
  • Monitor for unauthorized devices

FAQ: MAC Address Lookup

1. Can a device have multiple MACs?

Yes, devices with multiple network interfaces (WiFi, Ethernet, Bluetooth) each have MACs.

2. Are MACs unique?

Manufacturer MACs should be unique. Manually assigned can duplicate.

3. Can I change my MAC address?

Yes, OS allows MAC spoofing for privacy or testing.

4. What if vendor isn't found?

Newer devices or unusual vendors may not be in database yet.

5. Is MAC tracking illegal?

Using MAC to identify devices on your own network is legal.

6. Why are MAC addresses useful?

Unlike IP, MAC is hardware-based and persists across sessions.

7. What's the largest OUI database?

IEEE assigns OUIs. Commercial databases have 8000+ entries.

8. Can MACs be cloned?

Yes, MAC spoofing is trivial. Not reliable for security.

9. Do virtual machines have MACs?

Yes, they have virtual MACs assigned by hypervisor.

10. How find MAC on device?

Settings > About on phones. IPCONFIG /ALL on Windows.
